# 오답 탐정

정보과학 프로젝트 2회차용 오답 등록 화면입니다.

## 실행 방법

`index.html`을 더블 클릭하여 브라우저에서 엽니다.

## 이번 회차 구현 내용

- 과목, 단원, 문제 유형 입력
- 문제 이미지 선택
- 내가 쓴 답과 정답 입력
- 문제를 풀 당시의 상황 선택
- `오답 분석하기` 버튼을 누르면 입력 결과 표시
- 선택한 풀이 상황에 따라 오답 원인 분류
- 판단 이유, 확인할 개념, 다음 학습 행동 표시

현재 분석은 사용자가 선택한 상황을 기준으로 하는 규칙 기반 방식이며, 입력 내용은 데이터베이스에 저장되지 않습니다. 다음 단계에서는 분석 결과에 맞는 추천 문제 화면을 연결할 수 있습니다.
